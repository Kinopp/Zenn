# Oracle SQL 逆引き文法リファレンス

「実践的OracleSQL徹底演習（完全版）」第3章〜第18章で扱った構文・関数を、**「〜したい」という目的**から逆引きできるようにまとめたリファレンスです。各項目には、詳しい解説が載っている問題番号を記載していますので、忘れてしまったときや、似た構文と迷ったときの索引としてご活用ください。

:::message
本リファレンスは書籍本文の要約であり、各構文の詳細な挙動・注意点・エラーパターンについては、必ず該当する問題の解説本編をご参照ください。
:::

## 16. NULL処理・条件分岐 早見表（横断）

複数章にまたがって登場するNULL処理・条件分岐系の関数は混同しやすいため、まとめて整理します。

| 関数 | できること | 出典（代表例） |
| :--- | :--- | :--- |
| `NVL(式, 代替値)` | NULLのときだけ代替値に置き換える（型は1種類） | 5-9, 6-6 |
| `NVL2(式, 値1, 値2)` | NULLでなければ値1、NULLなら値2を返す | 5-9 |
| `COALESCE(式1, 式2, ...)` | 複数の式を左から評価し、最初にNULLでない値を返す | 5-9, 10-1 |
| `NULLIF(式1, 式2)` | 式1と式2が等しければNULLを返す（0除算対策など） | 6-6 |
| `DECODE(式, 値1, 結果1, ..., デフォルト)` | 等価比較のみの簡易分岐（CASE式の前身） | 5-3, 15-1 |
| `CASE WHEN ... THEN ... ELSE ... END` | 任意の条件式で柔軟に分岐（不等号・BETWEEN・IN等も可） | 4-8, 8-4, 9-10 |
