AIエージェントの解説って、OpenAIベースのものが多いですよね。API課金に怯えずに、もっと気軽に開発したい！そこで注目なのが、今トレンドのGemini 3系モデルです。Gemini 3系の Flash / Flash-Lite なら無料枠で試せます（Pro系は有料。無料枠はレート制限があり、送信データが製品改善に使われる点に注意）。OpenAIベースが多い中、今回は「Spring AI」を使って、Geminiでチャットさせる、最小実装を解説します。

## 1. APIキーの取得
#### ① [Google AI Studio](https://aistudio.google.com/api-keys) にアクセスします
#### ② 画面右上の [APIキーを作成] を押します
#### ③プロジェクトを選択するか新しく作成して、APIキー（AIzaSy... から始まるキー）を発行し、コピーします。

## 3. コードの追加
Gemini とやり取りをするための`ChatController`クラスを作成します。

```java
package com.example.demo;

import org.springframework.ai.chat.model.ChatModel;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class ChatController {

    private final ChatModel chatModel;

    // Spring AIが自動的にGeminiと通信するChatModelを準備してくれます
    public ChatController(ChatModel chatModel) {
        this.chatModel = chatModel;
    }

    // ブラウザで http://localhost:8080/ai/chat にアクセスした時に動く処理
    // http://localhost:8080/ai/chat?message=日本の首都はどこですか？ のように実行する。
    @GetMapping("/ai/chat")
    public String chat(@RequestParam(value = "message", defaultValue = "こんにちは！自己紹介をしてください。") String message) {
        // AIにメッセージを送信して、返ってきたテキストをそのままブラウザに返します
        return this.chatModel.call(message);
    }
}
```

## 4. `application.properties`の編集
以下を追加します。

**spring.ai.google.genai.api-key**
* 1で取得したAI..で始まるAPIキーを貼り付けます。
  
**spring.ai.google.genai.chat.model**
* モデルを選択します。今回は`gemini-3.1-flash-lite`を使用します。

```properties
spring.application.name=chat01

spring.ai.google.genai.api-key={1で取得したAI..で始まるAPIキー}
spring.ai.google.genai.chat.model=gemini-3.1-flash-lite
```
